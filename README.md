# Estante para iPhone e iPad

Leitor de EPUB e PDF que busca livros em acervos abertos (Project Gutenberg,
Internet Archive, catálogos OPDS), com destaques, notas e dicionário.

Este repositório só distribui o app pelo AltStore e pelo SideStore.

## Instalar

1. No AltStore (Classic) ou no SideStore, abra a aba **Sources** e toque em **+**.
2. Cole o endereço da source:

   ```
   https://github.com/b9rnardo/estante-ios/releases/latest/download/source.json
   ```

3. Em **Browse**, abra a Estante e instale.

O app é assinado com o seu Apple ID na instalação. Com um Apple ID gratuito a
assinatura vale 7 dias, e o AltStore ou o SideStore a renovam antes de vencer.
Versões novas aparecem como atualização no próprio AltStore.

O `.ipa` de cada versão também está em [Releases](https://github.com/b9rnardo/estante-ios/releases),
para instalar direto pelo arquivo.
